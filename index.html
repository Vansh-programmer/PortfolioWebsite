Behind the Scenes

A complete breakdown of the tech stack and features driving this portfolio.

Tech Stack

This entire portfolio is built using Vanilla HTML, CSS, and JavaScript. Zero bloated frameworks (like React or Vue) were used. This ensures lightning-fast load times and proves a deep, fundamental understanding of core web technologies.

Feature Breakdown

🐧 Linux Window Manager

The draggable floating windows were engineered from scratch in JavaScript. Event listeners track mouse coordinates to allow dragging, while a custom function manages z-index stacking to ensure the active window always comes to the front.

⌨️ Interactive Bash Terminal

The terminal engine intercepts raw keyboard events, maintains a history stack for Up/Down arrow navigation, and uses a custom string parser to execute commands against an in-memory JSON file system.

💻 3D Laptop Showcase

The laptop on the main website uses advanced CSS 3D transforms (perspective, rotateX, rotateY). JavaScript listens for scroll events and keyboard inputs (W, A, S, D) to animate the sliding projects inside the screen container.

✨ Hyprland Aesthetics

The glowing window borders and frosted top-bar rely on CSS backdrop-filter: blur() and dynamic box-shadow effects that transition instantly when a window gains focus.
